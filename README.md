# 🚗 Vehicle Service Center Management System

## 📖 Project Overview

The **Vehicle Service Center Management System** is a database-driven web application developed to automate and simplify the day-to-day operations of a vehicle service center. The application replaces traditional manual record-keeping with a digital system that efficiently manages customer details, vehicle information, service records, billing, payment tracking, and customer notifications. It provides an intuitive interface that enables service center staff to perform operations quickly and accurately while ensuring secure storage and retrieval of data.

The system is developed using **Python** and **Streamlit** for the frontend, while **Microsoft SQL Server (SSMS)** is used as the backend database. It supports different vehicle categories such as bikes and cars with separate pricing structures, allows multiple service selection, automatically calculates service charges, applies discounts, and maintains payment status. An integrated email notification feature informs customers when their vehicle service is completed and ready for pickup.

This project demonstrates the practical implementation of **Database Management System (DBMS)** concepts such as Entity Relationship Modeling, Relational Schema, Normalization, Primary and Foreign Keys, along with modern application development techniques to create an efficient, scalable, and user-friendly solution for vehicle service center management.
